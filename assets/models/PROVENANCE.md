# Model provenance

Every file under `assets/models/` must be listed here with its origin and
license before it is committed. Only original work, or third-party work under
a license that allows redistribution in this project, is allowed. Never add
models, textures or sounds extracted from World of Warcraft or any other game.

| File | Origin | Author | License | Notes |
|---|---|---|---|---|
| `props/forge_brazier.glb` | Generated by `scripts/make_prop_models.py` (deterministic; regenerate to verify) | Dungeon Sandbox contributors | MIT OR Apache-2.0 (same as the code) | Low-poly brazier: stone foot and stem, iron bowl, emissive coals and flame (`KHR_materials_emissive_strength`). No textures. |

## Adding a model

1. Put it under `assets/models/<category>/`, as `.glb` (preferred) or
   `.gltf` + `.bin`.
2. Add a row above: where it came from, who made it, its license, and a link
   to the source if it is third-party.
3. Reference it from content as a prop (`[[dungeon.props]]`, or a kit's
   `arena_prop`) with a primitive `fallback`. The game draws the fallback
   if the file is missing, so content never depends on the file.
4. Props are scenery. Their footprint must stay off walkable floor (the
   validator checks this), and they never change navigation.
